# Learning Log GR

## Φάση 0: Ξεκίνημα project

Σε αυτή τη φάση δεν γράφουμε ακόμα λειτουργίες. Πρώτα φτιάχνουμε το "μυαλό" του project: τι θέλουμε να χτίσουμε, ποια είναι τα όρια του MVP, ποια βήματα θα ακολουθήσουμε και πώς θα ελέγχουμε ότι κάθε βήμα δουλεύει.

### Τι έμαθε ο Νίκος
- Ένα MVP δεν ξεκινάει με πολλά features. Ξεκινάει με καθαρό στόχο.
- Η τεκμηρίωση δεν είναι αγγαρεία. Είναι τρόπος να θυμάσαι αποφάσεις και να εξηγείς το project σε συνέντευξη.
- Ο Coding Agent πρέπει να παίρνει μικρά, συγκεκριμένα prompts.
- Όσο πιο καθαρό είναι το prompt, τόσο πιο εύκολο είναι να ελέγξεις το αποτέλεσμα.

## Pivot: Από WordPress σε React

Ο Νίκος αποφάσισε να μη συνεχίσει το project ως WordPress plugin και να το κάνει React app. Αυτό είναι απολύτως λογικό αν ο στόχος είναι να δείξει React/front-end skills σε portfolio.

### Τι αλλάζει
- Δεν θα χτίσουμε WordPress plugin.
- Δεν θα χρησιμοποιήσουμε PHP, WordPress admin pages, shortcodes, `$wpdb`, ή WordPress REST API.
- Θα χρησιμοποιήσουμε React components, state, forms, localStorage, και dashboard UI.
- Το πρώτο React MVP δεν θα έχει backend. Θα αποθηκεύει προσωρινά data στο browser με localStorage.

### Γιατί ξεκινάμε με React + Vite skeleton
Το Vite είναι ένας απλός τρόπος να ξεκινήσεις React project. Μας δίνει dev server, γρήγορο refresh, και καθαρή δομή χωρίς να μπλέξουμε με πολλά εργαλεία από την αρχή.

### Τι να προσέξει ο Νίκος
- Να μη ζητήσει αμέσως dashboard, AI, backend και form όλα μαζί.
- Πρώτα πρέπει να τρέχει το React app.
- Μετά φτιάχνουμε data model.
- Μετά φόρμα.
- Μετά dashboard.
- Μετά analytics και mock AI.

Αυτός είναι πιο σωστός τρόπος μάθησης: μικρά βήματα, καθαρός έλεγχος, λιγότερο χάος.
